Step 2 — Update Nginx to enforce IP allowlist
SSH into your AWS instance:


bash
sudo nano /etc/nginx/sites-available/shipstation
Replace the contents with this (fill in your actual IP):


nginx

server {
    listen 80;
    server_name api.ancienthowl.net;
    return 301 https://$host$request_uri;
}

server {
    listen 443 ssl;
    server_name api.ancienthowl.net;

    ssl_certificate     /etc/letsencrypt/live/api.ancienthowl.net/fullchain.pem;
    ssl_certificate_key /etc/letsencrypt/live/api.ancienthowl.net/privkey.pem;
    include             /etc/letsencrypt/options-ssl-nginx.conf;
    ssl_dhparam         /etc/letsencrypt/ssl-dhparams.pem;

    # Block disallowed IPs at the Nginx level
    if ($allowed_ip = 0) {
        return 403;
    }

    location / {
        proxy_pass         http://localhost:3000;
        proxy_http_version 1.1;
        proxy_set_header   Host              $host;
        proxy_set_header   X-Real-IP         $remote_addr;
        proxy_set_header   X-Forwarded-For   $proxy_add_x_forwarded_for;
        proxy_cache_bypass $http_upgrade;
    }
}
Test and reload:


bash
sudo nginx -t
sudo systemctl reload nginx

Step 3 — Add API Key to server.js

Add one line to your .env:
bash
nano ~/shipstation-backend/.env

Add:
API_KEY=your-long-random-secret-here
Generate a strong key right now on the server:

bash
node -e "console.log(require('crypto').randomBytes(32).toString('hex'))"
Copy that output as your API_KEY value.
